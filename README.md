# Karan Sehra - IT Portfolio & Cyber Security Mentor

Modern, responsive high-tech portfolio website for **Karan Sehra** — IT Student, Cyber Security Mentor, and Technology Enthusiast from Bulandshahr, Uttar Pradesh.

## 🌟 Highlights
- **Cyber High-Tech Theme**: High-contrast Cyber Red (`#ff3355`), Pure White (`#ffffff`), and Emerald Green (`#00f59b`) color scheme with dark glassmorphic panels.
- **Interactive Live Wallpaper**: Custom HTML5 Canvas engine featuring 3 switchable animation presets (*Cyber Constellation Mesh*, *Matrix Rain*, and *Neon Tech Orbs*) with mouse and touch-drag interactivity.
- **Comprehensive Profiles & Specializations**:
  - **Specialization & Mentorship**: Cyber Security Mentor (threat analysis, system hardening, malware protection, ethical hygiene).
  - **Programming & Markup Languages**: HTML5, C, C++, Ruby.
  - **Core IT Skills**: Computer Hardware & Maintenance, Troubleshooting & BSOD Recovery, IT Support, LAN / Networking, Software & Applications, Digital Technology, AI & Emerging Tech.
  - **Academic Background**: ITI in ICTSM (Information and Communication Technology System Maintenance - 1st Semester), 12th Standard (2024), 10th Standard (2022).
  - **Computer Courses**: Basic Computer Course (March 2026), Advanced Computer Course (2026).
  - **Direct Channels**: Direct phone, email, and authentic brand SVG links for Instagram, Snapchat, and Facebook.
- **100% Pure Vanilla Web Stack**: Built with semantic HTML5, clean modern CSS3, and vanilla JavaScript (no npm, no node_modules, no external dependencies).
- **Mobile-First Responsive Design**: Optimized for smartphones, tablets, laptops, and ultra-wide displays with fluid navigation drawer and compact card architecture.
